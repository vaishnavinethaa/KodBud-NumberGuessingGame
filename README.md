# 🎯 Number Guessing Game

## Description
This project is a Number Guessing Game developed using Python as part of the KodBud Python Internship.

## Features
- Generates a random number between 1 and 100
- Accepts user guesses
- Provides "Too High" and "Too Low" hints
- Counts the total number of attempts
- Displays a success message when the correct number is guessed

## Technologies Used
- Python
- VS Code
